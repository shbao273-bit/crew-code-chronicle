# The Family Cypher

Create a bold, modern hip-hop inspired family introduction website featuring 5 family members. The website should feel like a streetwear magazine mixed with an underground hip-hop album. Use a dark black/charcoal background, strong red accents, graffiti-style details, oversized typography, sticker-like elements, ripped-paper textures, subtle grain, and dynamic animations.

Homepage: Create a dramatic hero section titled “THE FAMILY” with a subtitle like “5 PEOPLE. 1 CREW. 1 STORY.” Add a visual collage of the five members.

Family section: Display the 5 members as five individual profile cards. Each card should have a large photo placeholder, name, nickname, role in the family, personality, favorite thing, and a short funny description. Make every card visually unique while keeping the overall design consistent.

Interaction: Add hover effects where the profile card expands or moves slightly, revealing more information. Add smooth scrolling, subtle glitch effects, animated graffiti/sticker elements, and transitions between sections.

Style: Make it feel youthful, rebellious, energetic, playful, and genuinely hip-hop rather than corporate. Avoid making it look like a typical family website. Use bold condensed fonts, asymmetrical layouts, layered elements, torn-paper effects, spray-paint/graffiti details, and album-cover aesthetics.

Sections: Hero → Meet The Crew → Family Timeline → Fun Facts → Family Quote → Contact/Ending.

Important: Make the website fully responsive for mobile and desktop. Use placeholder images and text that can easily be replaced later. Keep the UI polished, visually striking, and cohesive.
